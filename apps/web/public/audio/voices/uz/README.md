### ⚙️ Texnik Talablar:
- **Format:** `.mp3` (yoki `.wav`)
- **Bitrate:** 128 kbps yoki 192 kbps (fayl hajmi 20-100 KB bo'ladi, juda tez yuklanadi)
- **Shovqinsiz (Studio quality):** Ovoz orqasida musiqa yoki shovqin bo'lmasligi, aniq va yoqimli tembrda aytilishi maqsadga muvofiq.
